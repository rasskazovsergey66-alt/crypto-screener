# 🔍 Crypto Screener

Автоматический парсер данных криптовалют с TradingView. Собирает информацию по **135 монетам** дважды в день:  
**в 9:00 и 21:00 по Екатеринбургу**. Данные обновляются в репозитории автоматически.



## ⚡ Зачем нужна эта кнопка

Нажмите на неё, чтобы **запустить парсер вручную** и получить свежий CSV-файл **прямо сейчас**, без ожидания расписания.  
Это удобно, если вам нужны актуальные данные внепланово.

[![Запустить парсер](https://img.shields.io/badge/🚀-Запустить_парсер-2ea44f?style=for-the-badge&logo=github)](https://rasskazovsergey66-alt.github.io/crypto-screener/)

После нажатия перейдите по ссылке, нажмите кнопку на открывшейся странице и через **1–2 минуты** скачайте обновлённый файл.
