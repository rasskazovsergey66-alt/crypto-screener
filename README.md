### 🚀 Запуск парсера вручную

Вы можете запустить сбор данных в любое время прямо через интерфейс GitHub.

[![Запустить вручную](https://shields.io)](https://github.com/rasskazovsergey66-alt/crypto-screener/actions/workflows/scrape-crypto.yml)

**Пошаговая инструкция:**

1. **Перейдите на страницу запуска** — нажмите на зеленую кнопку «ЗАПУСТИТЬ ПАРСЕР» выше (система попросит войти в аккаунт GitHub, если вы еще не авторизованы).
2. **Активируйте процесс** — в открывшемся окне в правой части экрана нажмите кнопку **Run workflow**, затем во всплывающем меню еще раз нажмите финальную зеленую кнопку **Run workflow**.
3. **Дождитесь окончания** — процесс сбора занимает **1–2 минуты**. В это время индикатор будет гореть желтым цветом, а после успешного завершения сменится на зеленую галочку.

*Результат:* Парсер автоматически загрузит данные по **135 монетам** с TradingView и создаст новый CSV-файл в корне вашего репозитория.
